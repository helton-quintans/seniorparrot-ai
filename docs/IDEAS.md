# SeniorParrot AI — Ideas & Technical Improvements

## High-Priority / Near-Term Polish

- **Initial / Empty State Redesign**: Avoid landing with pre-selected noise, an already-generated question, and visible answer/feedback cards before the user answers. Make question and feedback zones informative empty/ready states so the flow feels real.

## Future Product Ideas

- **Topic → Subtopic → Level Selection**: Add subtopics under broader areas (e.g., System Design -> caching, rate limiting, real-time, frontend system design, plus Senior/Staff level).
- **Quizzes by Topic / Question**: Low-friction multiple-choice or scenario-based quizzes for warming up when not ready for an open-ended answer, or for reviewing a topic from a different angle (keeping focus on interview scenarios rather than generic trivia).
- **Post-Feedback Study Suggestions**: Suggest targeted articles, videos, or concepts to review based on gaps identified in the feedback.
- **Onboarding (Later)**: Add a lightweight, skippable onboarding once core features stabilize and prove their value in practice.

## Shelved / Discarded Experiments

- **Browser / Heavy TTS Audio**: Discarded for now due to poor native voice quality for English practice and slow load times / device constraints (especially on mobile).
- **Answer Framing Guide (Checklist + Sentence Starters)**: Paused for now while evaluating how open-ended practice and study workflows evolve.
